## What each row is for

- **Majority class** — The floor. Anything not beating this has learned nothing.
- **Majority class per crop (crop given)** — Oracle floor: assumes the crop is known, which the model is never told. Beating this is the real bar.
- **Small CNN from scratch** — What transfer learning buys, in one row.
- **MobileNetV2 (transfer)** — Same budget, the older mobile backbone.
- **EfficientNetB0 (transfer)** — Same budget, ~6x the FLOPs. Stands in for EfficientNet-Lite0, which keras.applications does not ship.
- **MobileNetV3-Small (reference = the shipped recipe)** — Every ablation below changes exactly one thing from this row.
- **...no augmentation** — Isolates the whole augmentation stack.
- **...standard augmentation only** — Flips/affine/brightness — none of the realism transforms.
- **...realism augmentation, no BackgroundReplace** — Against the reference row this isolates BackgroundReplace alone — the transform Phase 3 and Phase 4 both lean on.
- **...without class weights** — Read this one in the per-class recall table: Potato_healthy has 152 train images against Tomato_YLCV's 5357.
- **...frozen backbone only (no fine-tuning)** — Same epoch count, all of it head-only: what phase 2 buys.
- **MobileNetV3-Small "minimalistic" (no SE, ReLU)** — docs/quantization_findings.md predicted this variant survives full INT8 where the standard one collapsed. --quantize tests it.
